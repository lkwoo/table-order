# Business Rules - U5 Table & Session

**작성일**: 2026-08-31 | **Unit**: U5

---

| # | 규칙 |
|---|------|
| R1 | (store_id, table_number) 유일. 중복 생성 시 409 |
| R2 | 세션 종료는 **단일 트랜잭션**: 이력 이동 + 현재 주문 삭제 + 새 세션 생성 원자적 처리. 실패 시 전체 롤백 |
| R3 | 이력은 스냅샷(menu_name/unit_price 포함) 저장 → 메뉴 변경/삭제와 독립(Q3) |
| R4 | 세션 종료 시 새 TableSession(새 id) 생성 → 이전 주문과 격리(C12 연계) |
| R5 | 과거 이력 보관 3개월. 조회는 시간 역순 |
| R6 | 날짜 필터: 모든 날짜 / 오늘 / 어제 / 범위 선택 |
| R7 | 테이블 비밀번호 4~10자리, bcrypt 해싱 |
| R8 | 세션 종료는 확인 팝업 후 실행(프론트), 성공/실패 피드백 |

## Property-Based Test 후보
- 세션 종료 전 현재 주문 합계 == 종료 후 이력에 추가된 주문 합계(누락/중복 없음)
- 세션 종료 후 현재 주문 목록은 항상 비어 있고 총액 0
- 트랜잭션 중간 실패 주입 시 상태 불변(원자성)
