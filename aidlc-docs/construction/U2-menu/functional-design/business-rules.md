# Business Rules - U2 Menu (고객 조회)

**작성일**: 2026-08-31 | **Unit**: U2 Menu

---

| # | 규칙 |
|---|------|
| R1 | 고객에게는 `is_active=true` 메뉴만 노출 |
| R2 | 정렬: 카테고리 display_order → 메뉴 display_order 오름차순 |
| R3 | 상세 표시 항목 = 메뉴명, 가격, 설명, 이미지 (요구사항 3.1.2, 알레르기/칼로리 없음) |
| R4 | 조회는 세션의 store_id 스코프로 제한 |
| R5 | image_url 부재 시 응답에 null, 프론트 기본 아이콘 |
| R6 | 가격은 정수 KRW로 반환(포맷팅은 프론트) |

## 성능
- 메뉴 로드 < 2초. 페이지네이션 불필요(메뉴 수 소규모), 전체 반환.
