## 3. 기능 요구사항

### 3.1 고객용 기능 (Customer Features)

#### 3.1.1 테이블 태블릿 자동 로그인 및 세션 관리
- **자동 로그인**: localStorage에 저장된 인증정보로 자동 로그인
- **세션 ID**: 테이블별 세션 추적용
- **세션 타입**: 테이블 전용 (사용자 로그인 불필요)

#### 3.1.2 메뉴 조회 및 탐색
- **카테고리별 분류**: 카테고리별 메뉴 표시
- **메뉴 정보**: 메뉴명, 가격, 설명, 이미지 (외부 URL)
- **이미지 최적화**: 모바일 태블릿 환경에 맞춘 로딩 최적화
- **카테고리 네비게이션**: 빠른 이동 지원

#### 3.1.3 장바구니 관리
- **메뉴 추가/삭제/수량 조절**
- **총 금액 실시간 계산**
- **localStorage 저장**: 페이지 새로고침 후에도 유지
- **장바구니 비우기**

#### 3.1.4 주문 생성
- **주문 내역 최종 확인**: 확인 후 주문 확정 버튼
- **주문 번호 표시**: 5초 표시 후 자동 리다이렉트
- **자동 장바구니 비우기**: 주문 성공 시
- **오류 처리**: 
  - 네트워크 오류 시 자동 재시도 (최대 3회)
  - 재시도 실패 시 에러 메시지 표시 및 장바구니 유지

#### 3.1.5 주문 내역 조회
- **현재 세션 주문만 표시**: 이전 식사 세션 제외
- **주문 정렬**: 시간 역순
- **주문 상태 실시간 업데이트**: 관리자 상태 변경 시 SSE로 즉시 반영
- **표시 정보**: 주문번호, 시각, 메뉴, 수량, 금액, 상태
- **페이지네이션**: 또는 무한 스크롤

---

### 3.2 관리자용 기능 (Admin Features)

#### 3.2.1 매장 인증
- **인증 방식**: 매장 ID + 사용자명 + 비밀번호
- **세션 유지**: 16시간
- **토큰**: JWT 기반
- **브라우저 새로고침**: 세션 유지
- **자동 로그아웃**: 16시간 후

#### 3.2.2 실시간 주문 모니터링
- **업데이트 방식**: Server-Sent Events (SSE)
- **반응 시간**: 2초 이내
- **오프라인 동작**: 네 (로컬 데이터 유지)
- **레이아웃**: 테이블별 카드 형태 (그리드)
- **카드 표시**:
  - 테이블 번호
  - 테이블 총 주문액
  - 최신 주문 n개 미리보기
- **카드 클릭**: 전체 메뉴 목록 상세 보기
- **신규 주문 강조**: 색상 변경 또는 애니메이션
- **주문 상태 변경**: 대기중 → 준비중 → 완료 (드롭다운/버튼)

#### 3.2.3 테이블 관리
- **테이블 초기 설정**: 테이블 번호 + 비밀번호 + 16시간 세션 생성
- **주문 삭제**: 확인 팝업 후 즉시 삭제, 테이블 총액 재계산
- **테이블 세션 종료**:
  - 확인 팝업 표시
  - 종료 시 현재 주문 내역을 과거 이력으로 이동
  - 테이블 현재 주문 목록 리셋 (총액 0)
  - 새 고객 즉시 시작 가능
  - 성공/실패 피드백 표시
- **과거 주문 내역 조회**:
  - "과거 내역" 버튼
  - 테이블별 과거 주문 목록 (시간 역순)
  - 각 주문: 주문번호, 시각, 메뉴, 금액, 완료시각
  - 날짜 필터링 기능
  - "닫기" 버튼으로 대시보드 복귀

#### 3.2.4 메뉴 관리
- **메뉴 조회**: 카테고리별
- **메뉴 등록**: 메뉴명, 가격, 설명, 카테고리, 이미지 URL
- **메뉴 수정**: 모든 필드 수정 가능
- **메뉴 삭제**: 삭제 기능
- **노출 순서 조정**: 드래그앤드롭 또는 순서 번호 조정
- **데이터 검증**: 필수 필드 검증, 가격 범위 검증

## 4. 비기능 요구사항 (Non-Functional Requirements)

### 4.1 성능
- **주문 생성**: 1초 이내
- **메뉴 로드**: 2초 이내
- **실시간 업데이트**: 2초 이내 (SSE)
- **이미지 로딩**: 모바일 환경 최적화

### 4.2 가용성
- **오프라인 지원**: 관리자 대시보드 로컬 동작 가능
- **재연결**: 네트워크 복구 후 자동 동기화
- **백업**: 장바구니 localStorage 자동 저장

### 4.3 보안
- **비밀번호 해싱**: bcrypt 사용
- **JWT 토큰**: 16시간 유효기간
- **HTTPS**: 프로덕션 배포 필수
- **입력 검증**: 모든 사용자 입력 검증

### 4.4 데이터 관리
- **과거 이력 보관**: 3개월
- **세션 격리**: 테이블별 세션 ID로 격리
- **세션 만료**: 16시간
- **데이터 정합성**: 트랜잭션 사용

### 4.5 확장성
- **테이블 수**: 10-20개 지원 (초기)
- **동시 사용자**: 20-30명 (태블릿 + 관리자)
- **데이터베이스**: PostgreSQL로 선형 확장 가능

## 10. 주요 설계 고려사항

### 10.1 세션 관리
- 고객: 테이블별 자동 세션 (초기 설정 후)
- 관리자: 16시간 JWT 토큰

### 10.2 실시간 통신
- SSE 사용으로 서버→클라이언트 push
- 고객: 주문 상태 변경 알림
- 관리자: 신규 주문 알림

### 10.3 데이터 격리
- 테이블별 세션 ID로 주문 격리
- 세션 만료 후 자동 이력 이동

### 10.4 오프라인 지원
- 관리자 대시보드: 로컬 주문 데이터 캐싱
- 고객 태블릿: localStorage로 장바구니 유지

### 10.5 오류 처리
- 네트워크 오류: 자동 재시도 (최대 3회)
- 주문 실패: 장바구니 유지
